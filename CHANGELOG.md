# Changelog

Все заметные изменения проекта фиксируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

Номер версии — git-тег (`vX.Y.Z`). `build.bat` читает его через `git describe --tags` и собирает `dist\FaTTY <версия> Setup.exe`, `dist\FaTTY <версия> OneFile.exe` и папку `dist\FaTTY <версия> Portable`.

## Как пометить релиз

1. Перенести пункты из `[Unreleased]` в новую секцию `## [x.y.z] — ГГГГ-ММ-ДД`.
2. Закоммитить изменения.
3. Поставить тег: `git tag vX.Y.Z` (патч / минор / мажор по SemVer).
4. Запушить тег: `git push origin vX.Y.Z` — GitHub Actions соберёт exe и опубликует релиз. Либо локально `build.bat` и загрузить файлы вручную.

Сборка не с тега получит суффикс вида `1.4.0-3-gabc1234` (три коммита после тега). Без тегов — `0.0.0-g<хеш>`.

## [Unreleased]

### Added

- Отказ от обновления запоминается: галочка **Больше не напоминать об этой версии** (по умолчанию включена). При старте та же версия больше не предлагается; более новая — снова. **Справка → Проверить обновления…** по-прежнему спрашивает.
- Кнопка **Переместить в папку**: несколько команд выделяются Ctrl/Shift+кликом и переносятся пачкой.
- Столбец **Папка** в списке команд (имя вкладки). Отключается в настройках: «Показывать столбец „Папка“».

### Changed

- Активная вкладка сильнее отделена от остальных: светлее, жирнее, с цветной полоской сверху; неактивные темнее и с приглушённым текстом.
- В списке команд снова цвет по последнему запуску: зелёный — успех, жёлтый — прочее (таймаут, прервано), красный — ошибка. Раньше системный цвет списка затирал раскраску строк.

### Added

- Вкладки папок, справки и настроек — силуэт как в Chrome: активная стыкуется с содержимым, остальные плоские с наведением.
- Скруглённые карточки списков/вывода и кнопки по всему интерфейсу.
- Журнал сохраняет полный консольный вывод команды (до 256 КБ на запись). Поиск в журнале смотрит и по выводу.

### Fixed

- `build.bat` из обычного cmd сам подхватывает VS 2022 (`vcvars64`) и при необходимости скачивает CMake и Ninja — больше не нужно открывать Developer Command Prompt.
- `build.bat` снова находит Inno Setup 6: `%ProgramFiles(x86)%` в `if exist` ломал поиск `ISCC.exe`, и Setup.exe не собирался. Директива `UninstallCloseApplications` в `fatty.iss` не существует в Inno Setup — компилятор из‑за неё обрывался.
- Скругление синих кнопок: убран оконный регион и обводка, фон под сглаживание заливается через GDI+. Радиус кнопок, вкладок и карточек уменьшен — лёгкое скругление вместо «пилюль».
- Кириллица в интерфейсе больше не отображается «крякозябрами». `wxConvCurrent = &wxConvUTF8` этого не лечил: неявное `wxString(const char*)` всегда идёт через `wxConvLibc`, то есть через ANSI-кодовую страницу (CP1251), и UTF-8-байты литералов превращались в «РќР°СЃС‚СЂРѕР№РєР°». Весь текст интерфейса переведён на широкие литералы `L"…"`, а UTF-8-строки из core/net приходят в UI только через `wxString::FromUTF8()`. Чтобы это не сломали заново, таргет `fatty` собирается с `wxNO_IMPLICIT_WXSTRING_ENCODING`: неявное преобразование `const char*` → `wxString` теперь ошибка компиляции.
- Escape закрывает журнал, справку, файлы и остальные диалоги.
- Релизная сборка: кэш vcpkg на GitHub Actions больше не добавляет суффикс `-dirty`, из‑за которого Inno Setup отклонял `VersionInfoVersion`.

### Changed

- Установщик сам закрывает запущенный FaTTY вместо «Закройте приложение». Если выполняется команда, идёт передача файла или открыто окно правки — спрашивает подтверждение; иначе закрывает без лишнего диалога. Настройки при этом сохраняются.
- Приложение переписано на **C++20** (wxWidgets, libssh2, OpenSSL). Сборка: CMake + vcpkg + `build.bat`. Конфиг, вольт и журнал совместимы с Python-версией.
- `OneFile.exe` — один нативный exe (статическая линковка), без распаковки PyInstaller.
- GitHub Actions (CI/Release): явный Ninja, pin vcpkg к `builtin-baseline`, кэш `vcpkg_installed` + binary cache, проверка артефактов `dist\` перед релизом.

### Added

- Папки команд у каждого VPS: вкладки справа, **Папка+** / **Переименовать** / **Удалить папку**. Команды без папки — вкладка **Общее**.
- В настройках можно выбрать **тёмную** или **светлую** тему.
- В окне правки команды работают Ctrl+C / Ctrl+V.
- В журнале можно удалить отдельную запись (кнопка **Удалить** или Delete).
- Колонка **Последний раз** у команд: код/статус и время последнего запуска из журнала.
- Кнопка **Сбросить в ~** у панели вывода: следующая команда стартует из домашней папки, а не из последней `cd`.
- **Справка** (F1): как пользоваться, клавиши, частые команды (копирование и подстановка в разовую) и советы. Меню **Справка → Частые команды**.
- Окно **Настройки…** (меню **Настройки**, Ctrl+,): поведение запуска, обновления, журнал, пути к PuTTY и OpenSSH, экспорт/импорт, смена мастер-пароля.
- **Экспорт** и **импорт** VPS, команд и настроек (меню **Файл** и вкладка «Данные» в настройках): добавление к текущим или полная замена; пароли — опционально.
- Опция «Разрешить короткий мастер-пароль (от 4 символов)» в настройках (вкладка «Безопасность») — только после первой настройки; при смене пароля короче 8 символов — подтверждение.
- Блокировка входа после 5 неудачных попыток мастер-пароля на 20 минут (параметры — в дополнительных настройках безопасности).
- Журнал запусков: дата и время, VPS, команда, код выхода и длительность. Окно **Файл → Журнал команд…** (Ctrl+J), кнопка **Журнал** у панели вывода. Повтор запуска, копирование записи, сохранение в файл.
- Проверка обновлений: **Справка → Проверить обновления…** (GitHub Releases, иначе теги). Опция проверки при запуске — в окне настроек (не чаще раза в сутки).
- Установщик Windows: `FaTTY <версия> Setup.exe` (Inno Setup поверх Portable; `fatty.iss`).
- Кнопка **Копия** для VPS (вместе с командами) и для отдельной команды.
- Положение модальных окон запоминается (у диалога команды — ещё и размер).
- Экран загрузки при старте, чтобы было видно, что приложение открывается.
- Окно **Файлы** у выбранного VPS: просмотр каталога по SFTP, загрузка и скачивание файлов, новая папка, удаление. В каждой папке строка `..` поднимает на уровень вверх. Слева значки папок и типов файлов Windows.
- Порядок команд выбранного VPS: **Вверх** / **Вниз** (Ctrl+↑ / Ctrl+↓), сортировка **По имени** (клик по заголовку «Название»). Клик по «Команда» сортирует по тексту команды.
- Панель **Вывод**: выделение мышью сразу копирует текст в буфер (как в PuTTY); Ctrl+C тоже работает.
- Кнопка **PuTTY**: открывает PuTTY для выбранного VPS с паролем или SSH-ключом из карточки (без ручного ввода пароля). OpenSSH-ключи конвертируются в `.ppk` внутри FaTTY (без puttygen). Если PuTTY не найден — предложение скачать или указать путь к `putty.exe` (путь запоминается).
- GitHub Actions: CI на push/PR в `main`; релиз по тегу `v*` (Windows-сборка Setup / OneFile / Portable.zip).

### Changed

- Двойной клик по команде и Enter в списке запускают её (как F5). Правка — **Изменить** или F2.
- Тёмное оформление окон: единая палитра с панелью вывода, акцентные кнопки запуска/сохранения, тёмный заголовок Windows.
- Пункты «Спрашивать перед запуском» и «Проверять обновления» перенесены в окно настроек.
- Версия берётся из git-тега, а не из `__version__` в коде.
- Сборка даёт три варианта: `FaTTY <версия> Setup.exe` (Inno Setup), `FaTTY <версия> OneFile.exe` и папка `FaTTY <версия> Portable`.
