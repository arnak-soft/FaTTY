# FaTTY

Небольшая утилита для Windows: несколько VPS, пароли/ключи, набор команд на каждый сервер и запуск по SSH с вашего компьютера.

Типичный сценарий: `git pull` и перезапуск процесса на сервере без ручного набора `ssh` каждый раз.

## Запуск без Python

Собранный файл: `dist\FaTTY <версия>.exe` (например `FaTTY 1.4.0.exe`). Его можно скопировать на рабочий стол или в любую папку — Python на компьютере не нужен.

Пересобрать exe:

```bat
build.bat
```

Версия берётся из git-тега (`git describe --tags`). Перед релизом допишите `CHANGELOG.md`, поставьте тег и соберите:

```bat
git tag v1.4.0
build.bat
```

## Запуск из исходников

Нужен Python 3.10+ (в PATH). Первый раз:

```bat
run.bat
```

## Как пользоваться

1. **Добавить VPS** — имя, хост/IP, порт (обычно 22), логин, пароль и/или путь к SSH-ключу.
2. При создании сервера можно включить **типовые команды**: Deploy (`git pull` + `pm2 restart`), отдельно pull/restart, логи, git status, состояние сервера, nginx. Каталог приложения, ветку git и имя процесса pm2 задаёте сами (по умолчанию `/var/www/app`, `main`, `app`).
3. Для уже добавленного VPS: кнопка **Пресеты…**. В диалоге новой команды список **Пресет** подставляет шаблон.
4. Выбрать команду → **Запустить (F5)**. Лог в нижней панели. **Стоп** обрывает сессию.
5. **Разовая команда** — выполнить что-то один раз, не сохраняя.
6. **Проверить связь** — `hostname` / `whoami` на выбранном VPS.

Опция «Login-shell (`bash -lc`)» включена по умолчанию, чтобы на сервере подхватывался `PATH` из `.bashrc`.

## Где хранятся данные

Конфиг: `%APPDATA%\FaTTY\config.json`

Пароли шифруются **DPAPI** текущей учётной записи Windows. Файл бесполезен на другом компьютере или у другого пользователя. Не коммитьте его в git и не выкладывайте в открытый доступ.

Known hosts SSH: `%APPDATA%\FaTTY\known_hosts`

Открыть папку: меню **Файл → Открыть папку конфига**.
