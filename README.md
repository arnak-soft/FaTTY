# FaTTY

Небольшая утилита для Windows: несколько VPS, пароли/ключи, набор команд на каждый сервер и запуск по SSH с вашего компьютера.

Типичный сценарий: `git pull` и перезапуск процесса на сервере без ручного набора `ssh` каждый раз.

Нативное приложение на C++ (wxWidgets + libssh2). Конфиг `%APPDATA%\FaTTY\config.json` совместим с прежней Python-версией.

## Сборка

Нужны Git и компилятор: Visual Studio 2022 (MSVC, workload «Разработка классических приложений на C++») или MinGW-w64. CMake 3.24+ и Ninja — если их нет в PATH, `build.bat` сам скачает портативные копии в `third_party\`. Зависимости подтягивает [vcpkg](https://github.com/microsoft/vcpkg) (клон в `third_party\vcpkg`, не в git). `build.bat` можно запускать из обычного cmd: он сам находит VS и вызывает `vcvars64`.

`build.bat` кладёт в `dist\` три варианта:

- **`FaTTY <версия> Setup.exe`** — установщик (Inno Setup): `Program Files`, ярлык в меню Пуск, удаление через «Приложения». Нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php) на машине сборки (`ISCC.exe`).
- **`FaTTY <версия> OneFile.exe`** — один статически собранный файл.
- **`FaTTY <версия> Portable\`** — папка. Запускайте `FaTTY.exe` внутри.

```bat
build.bat
```

Или вручную (MSVC):

```bat
cmake --preset msvc-static
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Версия берётся из git-тега. Перед релизом допишите `CHANGELOG.md`, закоммитьте и поставьте тег:

```bat
git tag v0.1.0
git push origin v0.1.0
```

Push тега `v*` запускает GitHub Actions: Windows-сборка (`build.bat` + Inno Setup) и публикация на [Releases](https://github.com/arnak-soft/FaTTY/releases).

## Как пользоваться

1. **Добавить VPS** — имя, хост/IP, порт (обычно 22), логин, пароль и/или путь к SSH-ключу. Команды не создаются автоматически.
2. Для уже добавленного VPS: кнопка **Пресеты…** добавляет шаблоны (Deploy, git pull, pm2, nginx и т.п.). В диалоге новой команды список **Пресет** подставляет шаблон.
3. Выбрать команду → **Запустить (F5)**, двойной клик или Enter. Правка — **Изменить** или F2. У команды можно оставить **комментарий** — колонка в списке и подсказка при подтверждении запуска. В колонке **Последний раз** — код и время прошлого запуска; **Ср. время** — среднее по журналу. Порядок: **Вверх** / **Вниз** (Ctrl+↑ / Ctrl+↓) или **По имени**. Клик по заголовку «Название», «Комментарий», «Команда» или «Ср. время» тоже сортирует. Лог в нижней панели; **Сбросить в ~** возвращает рабочую папку в домашнюю. **Стоп** обрывает сессию. Каждый запуск пишется в **Журнал** (меню **Файл → Журнал команд…**, Ctrl+J или кнопка у панели вывода): дата и время, VPS, команда, код выхода, длительность и весь консольный вывод.
4. **Разовая команда** — выполнить что-то один раз, не сохраняя.
5. **Проверить связь** — `hostname` / `whoami` на выбранном VPS.
6. **PuTTY** — открыть PuTTY с паролем или ключом из карточки VPS (нужен установленный `putty.exe`). OpenSSH-ключ (`id_ed25519` и т.п.) FaTTY сам переводит в `.ppk`.
7. **WinSCP** — то же для WinSCP (SFTP). Если программа не найдена — можно скачать или указать путь к `WinSCP.exe`.
8. **Другие программы** — в **Настройки → Программы** добавляются свои кнопки. В аргументах работают подстановки `{host}`, `{port}`, `{user}`, `{password}`, `{key}`, `{ppk}`, `{name}`, `{sftp_url}`, `{ssh_target}`. Пути и список сохраняются в конфиге.
9. **Справка** (F1) — как пользоваться, клавиши, частые команды (можно скопировать или подставить в разовую) и советы. **Справка → Проверить обновления…** сверяет версию с [релизами на GitHub](https://github.com/arnak-soft/FaTTY/releases). При старте проверка тоже возможна (Настройки).

Опция «Login-shell (`bash -lc`)» включена по умолчанию, чтобы на сервере подхватывался `PATH` из `.bashrc`.

## Где хранятся данные

Конфиг: `%APPDATA%\FaTTY\config.json`

Резервные копии: `%APPDATA%\FaTTY\backups\` — раз в сутки, последние 14 файлов. Отключается в **Настройки → Данные**. Восстановление: скопировать нужный `config-….json` обратно как `config.json` (при закрытом FaTTY).

Пароли шифруются **DPAPI** текущей учётной записи Windows. Файл бесполезен на другом компьютере или у другого пользователя. Не коммитьте его в git и не выкладывайте в открытый доступ.

Known hosts SSH: `%APPDATA%\FaTTY\known_hosts`

Журнал запусков: `%APPDATA%\FaTTY\journal.jsonl` (без паролей; хранятся имя VPS, адрес, текст команды, код выхода, длительность и консольный вывод).

Открыть папку: меню **Файл → Открыть папку конфига**.
