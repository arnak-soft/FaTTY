# FaTTY

Утилита для Windows: несколько VPS, сохранённые команды и запуск по SSH с вашего компьютера. Типичный сценарий — `git pull` и перезапуск процесса, без ручного `ssh` каждый раз.

Скачать: [релизы на GitHub](https://github.com/arnak-soft/FaTTY/releases).

- **Setup.exe** — установка в Program Files, ярлык в меню Пуск, удаление через «Приложения».
- **OneFile.exe** — один файл, без установки.
- **Portable** — папка. Запускайте `FaTTY.exe` внутри.

## Как начать

1. При первом запуске задайте **мастер-пароль**. Им шифруются пароли VPS. Фразу восстановить нельзя.
2. **Добавить VPS** — имя, хост или IP, порт (обычно 22), логин, пароль и/или путь к SSH-ключу.
3. Команды сами не создаются. **Пресеты…** добавляет шаблоны (деплой, git pull, pm2, nginx), **Добавить** — свою команду.
4. Выберите команду → **Запустить** (F5), двойной клик или Enter. Если уже выполняется другая, выбранные встают в очередь. **Стоп** прерывает текущую и сбрасывает очередь.

Клавиши, примеры команд и подробности окон — **Справка (F1)**.

## Что есть в окне

Слева список VPS, справа вкладки **Группы** и **Связки**, внизу **Вывод** и **Shell**. У команды колонка **Итог** (OK, ошибка, таймаут, прервано, сбой) рядом с цветом строки. Меню, галочки, выпадающие списки, полосы прокрутки, индикатор загрузки и подтверждения запуска, удаления и выхода в цветах окна. Enter удаление и выход не подтверждает. Кнопка в фокусе обведена.

- **Группы** — вкладки команд. Новая группа — кнопка **Группа** или правый клик по вкладке. Без группы команды лежат на вкладке **Общее**. У команды можно задать каталог, комментарий и предупреждение перед запуском. В правке (F2) текст команды сверху, каталог и shell — в блоке **Запуск**. Правка и удаление — правый клик по строке.
- **Связка** — несколько команд этого VPS подряд, с паузой из правки связки. **По шагам** (или двойной клик) запускает шаги вручную. Ошибка на шаге останавливает автозапуск.
- **Shell** — терминал к выбранному VPS внутри FaTTY. Работает параллельно с F5. Галочка **Вывод команд сюда** показывает результат запуска в терминале. Размер шрифта терминала и панели **Вывод** — **Настройки → Общие → Окно** (по умолчанию 12).
- **Файлы** — передача по SFTP. **Открыть консоль** — внешний `ssh.exe`. **PuTTY** и **WinSCP** открываются с паролем или ключом из карточки (OpenSSH-ключ переводится в `.ppk`). Свои кнопки — **Настройки → Программы**.
- **Проверить связь** — короткий заход на выбранный VPS. **Состояние** (Ctrl+H) — CPU, RAM, Swap, диск и нагрузка относительно ядер; между проверками видно рост RAM, Swap и диска. Само по себе сервер не опрашивается, пока автоопрос не включён в **Настройки → Состояние**.
- **Разовая команда** — выполнить текст один раз, не сохраняя.
- **Журнал** (Ctrl+J) — дата, VPS, команда, код выхода, длительность и вывод.
- **Справка → Проверить обновления…** сверяет версию с релизами. После обновления при первом запуске показывается окно **Что нового**.

## Данные

Всё лежит в `%APPDATA%\FaTTY\`. Папка открывается из меню **Файл → Открыть папку конфига**.

- `config.json` — серверы, команды, связки и настройки. Пароли зашифрованы мастер-паролем и DPAPI текущей учётной записи Windows: файл не откроется на другом компьютере или у другого пользователя.
- `backups\` — копия конфига раз в сутки, хранятся последние 14. Отключается в **Настройки → Данные**. Чтобы вернуть копию, закройте FaTTY и положите нужный файл обратно как `config.json`.
- `known_hosts` — отпечатки SSH-серверов.
- `journal.jsonl` — журнал запусков. Паролей нет, текст вывода команд есть.
- `health.json` — последние и прошлые замеры состояния (до 48 на VPS), без паролей.

**Файл → Экспорт…** / **Импорт…** переносят набор на другой компьютер. Пароли в файл не попадают, пока это не отметить; тогда они лежат там открытым текстом. Импорт спрашивает отдельно: добавить к текущим или заменить всё.

## Сборка из исходников

На Windows: `build.bat` (Visual Studio 2022 с C++ или MinGW-w64 в PATH). Готовые файлы появляются в `dist\`. Номер версии берётся из git-тега.
