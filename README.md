# FaTTY

Небольшая утилита для Windows: несколько VPS, пароли/ключи, набор команд на каждый сервер и запуск по SSH с вашего компьютера.

Типичный сценарий: `git pull` и перезапуск процесса на сервере без ручного набора `ssh` каждый раз.

## Запуск без Python

`build.bat` кладёт в `dist\` два варианта. Python на целевом компьютере не нужен.

- **`FaTTY <версия> OneFile.exe`** — один файл, можно скопировать куда угодно. Старт медленнее: при каждом запуске распаковывается во временную папку.
- **`FaTTY <версия> Portable\`** — папка. Запускайте `FaTTY.exe` внутри. Старт заметно быстрее; копировать нужно всю папку целиком.

Пересобрать:

```bat
build.bat
```

Версия берётся из git-тега (`git describe --tags`). Перед релизом допишите `CHANGELOG.md`, поставьте тег и соберите:

```bat
git tag v1.4.0
build.bat
```

## Запуск из исходников

Нужен Python 3.10+ (в PATH). Первый раз:

```bat
run.bat
```

## Как пользоваться

1. **Добавить VPS** — имя, хост/IP, порт (обычно 22), логин, пароль и/или путь к SSH-ключу. Команды не создаются автоматически.
2. Для уже добавленного VPS: кнопка **Пресеты…** добавляет шаблоны (Deploy, git pull, pm2, nginx и т.п.). В диалоге новой команды список **Пресет** подставляет шаблон.
3. Выбрать команду → **Запустить (F5)**. Порядок команд: **Вверх** / **Вниз** (Ctrl+↑ / Ctrl+↓) или **По имени**. Клик по заголовку «Название» или «Команда» тоже сортирует. Лог в нижней панели. **Стоп** обрывает сессию.
4. **Разовая команда** — выполнить что-то один раз, не сохраняя.
5. **Проверить связь** — `hostname` / `whoami` на выбранном VPS.

Опция «Login-shell (`bash -lc`)» включена по умолчанию, чтобы на сервере подхватывался `PATH` из `.bashrc`.

## Где хранятся данные

Конфиг: `%APPDATA%\FaTTY\config.json`

Пароли шифруются **DPAPI** текущей учётной записи Windows. Файл бесполезен на другом компьютере или у другого пользователя. Не коммитьте его в git и не выкладывайте в открытый доступ.

Known hosts SSH: `%APPDATA%\FaTTY\known_hosts`

Открыть папку: меню **Файл → Открыть папку конфига**.
